# 父子会话层级视图方案

> 基于：[05-会话层级与父子关系调研.md](../00-调研分析/05-会话层级与父子关系调研.md)
> 关联模块：[02-会话浏览.md](../03-功能模块/02-会话浏览.md)

## 一、设计目标

在会话列表中直观展示根会话与子会话的层级关系，支持一键展开/收起、批量迁移、键盘导航。

## 二、UI 交互设计

### 2.1 列表展示
- 默认仅显示根会话（parent_id IS NULL）
- 切换按钮：「只看根会话」/「显示全部」
- 根会话行显示「子会话数」列（带 👶 图标按钮）
- 点击 👶 按钮：内联展开该根会话的子会话列表（缩进显示）

### 2.2 子会话展开
- 展开后子会话行缩进 1 级，显示 parent_id 指向的根会话标题
- 子会话行不显示「子会话数」列（避免嵌套）
- 再次点击 👶 收起

### 2.3 键盘导航（v1.1.0 新增）
| 按键 | 行为 |
|------|------|
| j | 下一行 |
| k | 上一行 |
| Enter | 打开详情 |
| d | 删除当前会话 |

### 2.4 批量迁移（v1.2.0 新增）
- 勾选多个根会话后，顶部出现「📁 迁移」按钮
- 点击迁移按钮：弹出目录选择对话框
- 选择目录后：批量更新 session.directory 与 project_id
- 迁移完成自动刷新列表

## 三、数据查询

### 3.1 根会话列表
```sql
SELECT s.*, COUNT(s2.id) AS child_count
FROM session s
LEFT JOIN session s2 ON s2.parent_id = s.id
WHERE s.parent_id IS NULL
  AND (s.project_id = ? OR ? IS NULL)  -- 项目筛选
ORDER BY s.time_updated DESC
LIMIT ? OFFSET ?
```

### 3.2 子会话展开
```sql
SELECT * FROM session WHERE parent_id = ? ORDER BY time_created ASC
```

### 3.3 兼容性检测
```sql
-- 检测 parent_id 列是否存在
SELECT COUNT(*) FROM pragma_table_info('session') WHERE name = 'parent_id'
```
- 返回 0：回退为「全部会话」模式，不展示层级 UI

## 四、批量迁移 IPC

```typescript
// shared/ipc-channels.ts

```

主进程实现：
1. 校验 sessionIds 非空、targetDirectory 存在
2. 事务内批量 UPDATE session SET directory=?, project_id=? WHERE id IN (...)
3. 返回成功迁移数

## 五、性能考虑

- 子会话数通过 LEFT JOIN + COUNT 一次性查询，避免 N+1
- 子会话展开采用懒加载（点击 👶 时才查询）
- 批量迁移使用事务，失败时整体回滚

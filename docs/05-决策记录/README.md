# 决策记录（ADR）

> Architecture Decision Records — 记录项目中重大技术决策的背景、方案与理由。

## 编号规范

- 文件命名：`NNNN-决策标题.md`（4 位数字，从 0001 起递增）
- 编号不复用：已废弃的 ADR 编号不可重新使用
- 状态流转：提议中 → 已接受 → 已废弃 / 已被 NNNN 取代

## 何时新增 ADR

以下场景必须新增 ADR：

- 技术选型（框架、库、数据库等）
- 架构变更（进程模型、通信方式、目录结构等）
- 功能移除（已发布功能的删除）
- 重大命名/品牌变更
- 安全策略调整

## ADR 模板

```markdown
# NNNN-决策标题

- **状态**：提议中 ｜ 已接受 ｜ 已废弃 ｜ 已被 NNNN 取代
- **日期**：YYYY-MM-DD
- **决策者**：Webb + 架构师 Agent

## 背景

（为什么需要做这个决策？遇到了什么问题？）

## 决策

（最终选择了什么？）

## 备选方案

- 方案 A：...
- 方案 B：...

## 理由

（为什么选这个？权衡了什么？）

## 影响

（这个决策带来的后果、约束、后续工作）
```

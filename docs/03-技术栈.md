# 技术栈

## 选型明细

| 层面 | 方案 | 实际版本 | 理由 |
|------|------|---------|------|
| 桌面框架 | Electron | ^30.0.1 | 成熟稳定，Node.js 生态完备，社区最大 |
| 前端 | React | ^18.2.0 | 生态最丰富，与 shadcn/ui 完美配合 |
| 语言 | TypeScript | ^5.2.2 | 全栈类型安全，与 OpenCode 一致 |
| 样式 | Tailwind CSS | ^4.0.0 | 原子化 CSS，开发效率高，无需额外组件库 |
| 图表 | Recharts | ^2.15.0 | React 原生声明式，比 ECharts 轻，仪表盘场景足够 |

| 路由 | React Router | ^7.0.0 | 标准方案，支持布局路由和动态参数 |
| 表格 | @tanstack/react-table | ^8.20.0 | 功能强大的表格库，支持排序、筛选、分页等高级功能 |
| 图标 | Lucide React | ^0.460.0 | 轻量一致，图标覆盖全面 |
| Markdown | react-markdown | ^9.0.1 | 消息内容渲染，支持 GFM 和代码高亮 |
| GFM 插件 | remark-gfm | ^4.0.0 | GitHub 风格 Markdown 扩展 |
| 代码高亮 | rehype-highlight | ^7.0.1 | 代码块语法高亮 |
| SQLite | better-sqlite3 | ^11.7.0 | 同步 API，性能优异，Electron 首选 |
| 构建 | Vite | ^5.1.6 | 快速 HMR，Electron 插件成熟 |
| Electron 集成 | vite-plugin-electron | ^0.28.6 | Vite + Electron 无缝集成 |
| 渲染进程集成 | vite-plugin-electron-renderer | ^0.14.5 | 渲染进程 Node API 支持 |
| 打包 | electron-builder | ^24.13.3 | macOS/Windows/Linux 三平台 |
| 测试 | Vitest | ^2.1.0 | 单元测试，与 Vite 深度集成 |
| E2E 测试 | Playwright | ^1.49.0 | 浏览器端到端测试 |
| 测试数据 | tsx | ^4.19.0 | 运行 TypeScript 测试数据生成脚本 |

## 明确不引入

| 项目 | 理由 |
|------|------|
| ORM（Drizzle/Prisma） | 分析场景用原始 SQL 更透明，无需迁移管理 |
| Redux | 应用规模适中，Zustand 已满足需求，Redux 样板代码过多 |
| CSS-in-JS（styled-components） | Tailwind 已覆盖样式需求 |
| ECharts | Recharts 更轻，声明式 API 更适合 React |
| shadcn/ui | 最终实现使用原生 HTML + Tailwind，无需组件库依赖 |
| Next.js | 桌面应用不需要 SSR |
| Tauri | Electron 生态更成熟，better-sqlite3 直连更方便 |

# 待办管理

> 新增于 v1.4，增强于 v1.5

## 设计目标

查看 AI 助手的待办清单，从待办视角理解会话目标与执行进度。

## 数据来源

| 数据 | IPC 通道 | SQL / 来源 |
|------|---------|-----------|
| 全局待办列表 | `todos:list` | `SELECT t.*, s.title, s.directory FROM todo t JOIN session s ... WHERE t.content LIKE ? AND t.status = ? AND t.priority = ? AND s.directory = ? ORDER BY t.time_created DESC` |
| 单会话待办 | `todos:bySession` | `WHERE t.session_id = ? ORDER BY t.position ASC` |

## 表格字段

| 列 | 来源 | 说明 |
|----|------|------|
| 待办内容 | `todo.content` | 前缀 `[position] ` 拼接 content，截断 120 字符 |
| 状态 | `todo.status` | 彩色 badge：⏳待处理/🔄进行中/✅完成/🚫取消 |
| 优先级 | `todo.priority` | 彩色 badge：🔴高/🟡中/🟢低 |
| 所属会话 | JOIN `session.title` | 点击跳转 `/sessions/{sessionId}` |
| 所属项目 | JOIN `session.directory` | 工作目录路径，筛选通过 SESSIONS_PROJECTS 获取可选项目列表 |

## 筛选能力

| 筛选器 | 实现 | 说明 |
|--------|------|------|
| 搜索 | `WHERE content LIKE ?` | 实时防抖 300ms |
| 按状态 | `WHERE status = ?` | 下拉：全部/待处理/进行中/已完成/已取消 |
| 按优先级 | `WHERE priority = ?` | 下拉：全部/高/中/低 |
| 按项目 | `WHERE s.directory = ?` | 下拉选项来自 `sessions:projects` IPC，按工作目录筛选 |
| 按 pageSize | `LIMIT ? OFFSET ?` | 下拉：10/20/50，默认 20 条/页，通过 `localStorage` 持久化 |

## 交互

- **点击行**：跳转到该会话的消息页面（`/sessions/{sessionId}/messages`）
- **状态/优先级**：只读展示，不支持编辑（v1.4 第一版）

# 清理向导

## 设计目标

安全、可控、可预览地清理历史数据。杜绝误删。

## 流程

```
步骤 1: 选择策略
    │
    ▼
步骤 2: 预览影响范围
    │
    ▼
步骤 3: 确认执行
```

顶部步骤指示器显示当前步骤，已完成步骤显示 ✓ 图标。

## 步骤 1 — 选择策略

```
┌──────────────────────────────────────┐
│  选择清理策略                          │
│  选择一种策略来筛选需要清理的会话数据    │
│                                      │
│  ○ 按时间 🕐 删除指定天数前的旧会话     │
│    ── 选中后展开 ──                   │
│    删除 [90] 天前的会话               │
│                                      │
│  ○ 按大小 💾 删除数据量超过阈值的会话   │
│    删除大于 [50] MB 的会话            │
│                                      │
│  ○ 按项目 📂 删除指定项目的所有会话     │
│    选择项目 [my-talk ▾]              │
│                                      │
│  ○ 自定义 💻 使用自定义 SQL WHERE 条件 │
│    WHERE 条件: s.time_created < ...   │
│    提示: 表别名 s=session             │
│                                      │
│                    [下一步: 预览 →]    │
└──────────────────────────────────────┘
```

**四种策略**：

| 策略 | 图标 | 条件 | 参数 |
|------|------|------|------|
| 按时间 | 🕐 Clock | `WHERE s.time_updated < ?` | `days`（默认 90） |
| 按大小 | 💾 HardDrive | `HAVING SUM(LENGTH(data)) > ?` | `sizeMB`（默认 50） |
| 按项目 | 📂 FolderOpen | `WHERE s.project_id = ?` | `projectId`（下拉选择） |
| 自定义 | 💻 Code | 用户输入 WHERE 子句 | `customWhere` |

**策略选择交互**：
- Radio 按钮选择，选中项蓝色高亮边框 + 蓝色背景
- 选中后展开参数输入区域
- 参数校验：数字必须 > 0，项目必须选择，自定义条件不能为空
- "下一步"按钮在参数无效时禁用

**关键行为**：
- 预览阶段只读，不修改任何数据
- 4 个彩色统计卡片实时更新（红/橙/黄/紫）
- 会话列表可逐个取消勾选（`excludedSessionIds`）
- 全选/全不选快捷操作
- 取消勾选的会话变灰 + 降低透明度
- 统计数据根据勾选状态动态计算
- 无选中会话时"确认清理"按钮禁用

## 清理 SQL 逻辑

```sql
-- 1. 先删除 part
DELETE FROM part WHERE session_id IN (SELECT id FROM session WHERE <筛选条件>);

-- 2. 删除 message
DELETE FROM message WHERE session_id IN (SELECT id FROM session WHERE <筛选条件>);

-- 3. 删除 session
DELETE FROM session WHERE <筛选条件>;

-- 4. 回收空间
VACUUM;
```

执行顺序严格遵循外键约束：part → message → session。

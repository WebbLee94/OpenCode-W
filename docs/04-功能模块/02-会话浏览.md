# 会话浏览

## 设计目标

快速找到目标会话，一眼看懂哪些会话占空间最大。

## 实际布局

```

│                                                      │
│  ┌──────────────────────────────────────────────┐    │
```

## 列表字段

| 列 | 来源 | 说明 |
|----|------|------|
| 标题 | `session.title` | 可截断显示，hover 完整标题 |
| 消息数 | LEFT JOIN 子查询 `COUNT(message.id)` | 格式化数字 |
| 数据大小 | LEFT JOIN 子查询 `SUM(LENGTH(part.data))` | 格式化显示（KB/MB/GB） |
| Token 消耗 | `tokens_input + tokens_output` | 总和，可排序 |
| 最近活跃 | `session.time_updated` | 相对时间（"2 天前"） |
| 所属项目 | `session.project_id` | 截断显示 |

## 筛选能力

| 筛选器 | 实现 | 说明 |
|--------|------|------|
| 搜索 | `WHERE (s.title LIKE ? OR s.id LIKE ?)` | 300ms 防抖 |
| 按项目 | `WHERE s.project_id = ?` | 下拉选择，从 `sessions:projects` 获取列表 |
| 排序字段 | `ORDER BY s.${safeSortBy}` | 白名单校验，支持 5 种排序 |
| 排序方向 | `ASC / DESC` | 切换按钮 |

### 排序选项

| 值 | 标签 |
|----|------|
| `time_updated` | 最近活跃（默认） |
| `title` | 标题 |
| `msg_count` | 消息数 |
| `data_size` | 数据大小 |
| `total_tokens` | Token 消耗 |

## 详情面板

右侧滑出面板（480px），展示单会话的聚合统计：

### 基础信息
- 会话标题
- 目录路径
- 模型名称
- 时间范围（创建 ~ 更新）

### Token 明细
- 环形饼图（Recharts PieChart）：Input / Output / Reasoning / Cache Read / Cache Write
- 预估费用
- 缓存命中率

### Tool 使用排行
- 横向柱状图（TOP 5）
- 渐变透明度效果

### Skill 列表
- 紫色圆角标签（Badge）展示

### 📋 Todo 列表（v1.4+）
- 以 Tab 形式切换：`[基本] [Token] [Tool] [Skill] [📋Todos(N)]`
- 4 个前端筛选 Tab：全部 / 待处理 / 进行中 / 已完成
- 每项显示：优先级图标（🔴高🟡中🟢低）+ 状态图标（⏳待处理🔄进行中✅完成🚫取消）+ content 文本
- 按 position 排序（保持原始顺序）
- 数据来源：`todos:bySession` → `electron/ipc/todos.ts`
- 无分页（单会话 todo 通常不超过几十条）

### 📤 分享信息（v1.4+）
仅在该 session 有分享记录时条件渲染（无数据不显示空白框）：
- 分享链接（可复制到剪贴板）
- 分享 ID
- 创建时间
- 密钥（默认脱敏 `********`，点击 👁 按钮显示/隐藏）
- 数据来源：`session-share:get` → `electron/ipc/sessions.ts`

### 操作按钮
- **查看消息**：跳转到 `/sessions/:sessionId/messages`
- **删除此会话**：弹出确认对话框 → 调用 `sessions:delete`

## 行操作

- 单击：展开详情面板（右侧滑出）
- 详情面板内 [查看消息] 按钮：跳转到消息查看器
- 详情面板内 [删除此会话]：弹出确认框 → IPC 调用 `sessions:delete`

## 分页

- 默认 50 条/页
- 显示 "显示 1-50 / 共 2,858 条"
- 支持页码输入跳转
- 上一页/下一页按钮

## 删除确认

```
┌─────────────────────────────┐
│  确认删除                    │
│  确定要删除此会话吗？         │
│  此操作将删除该会话的所有     │
│  消息和 Part 数据，且不可恢复。│
│                             │
│  [取消]        [确认删除]    │
└─────────────────────────────┘
```

删除成功后自动从列表移除，关闭详情面板。

# 账户管理

> 新增于 v1.4

## 设计目标

查看 OpenCode 的 AI API 账户配置状态，了解当前活跃账户和 Token 到期情况。

## 实际布局

```
┌─ Accounts ────────────────────────────────────────────────────┐
│                                                               │
│  ┌─ 📍 当前活跃账户 ───────────────────────────────────────┐ │
│  │  ✅ 已激活   webb@example.com                            │ │
│  │  🌐 https://api.anthropic.com                            │ │
│  │  🏢 组织: org_abc123                                     │ │
│  │  ⏰ Token 过期: 2026-06-21 (30天后)                      │ │
│  └─────────────────────────────────────────────────────────┘ │
│                                                               │
│  ┌─ 📋 全部账户 ──────────────────────────────────────────┐ │
│  │  # │ 邮箱                   │ 服务              │ 状态   │ │
│  │  1 │ webb@example.com  👑   │ api.anthropic.com  │ 🟢活跃 │ │
│  │  2 │ dev@example.com       │ api.openai.com     │ ⚪未激活│ │
│  └─────────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────┘
```

## 数据来源

| 数据 | IPC 通道 | SQL / 来源 |
|------|---------|-----------|
| 活跃账户 | `accounts:active` | `SELECT * FROM account_state LEFT JOIN account ON active_account_id = account.id LIMIT 1` |
| 全部账户 | `accounts:list` | `SELECT id, email, url, token_expiry FROM account ORDER BY time_created DESC` |

## 页面区域

### 当前活跃账户（上方卡片）
- 从 `account_state` JOIN `account` 提取
- 显示：邮箱、服务 URL、组织 ID、Token 过期倒计时
- 若未配置账户，显示「未配置活跃账户」

### 全部账户（下方表格）
- 数据来源：`account` 表全部记录
- 列：邮箱 | 服务地址 | Token 过期时间 | 是否活跃标记
- **access_token / refresh_token 默认不展示**（安全敏感字段）

## 安全处理

| 字段 | 处理方式 |
|------|---------|
| `account.access_token` | IPC handler **不返回**，前端无法接触 |
| `account.refresh_token` | IPC handler **不返回**，前端无法接触 |
| `account_state.active_account_id` | 正常返回（仅 ID，无敏感信息） |

## 交互

- 只读查看，不支持编辑/删除（v1.4 第一版）
- 无活跃账户时展示空状态提示

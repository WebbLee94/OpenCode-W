## 设计目标

逐条查看会话内容，理解一条消息到底占多少空间、包含哪些 part。

## 路由

- 路径：`/sessions/:sessionId/messages`
- 从会话浏览页点击"查看消息"跳转
- 面包屑：首页 > 会话浏览 > 消息查看器

## 消息列表（左侧，40%宽度）

| 显示 | 说明 |
|------|------|
| 序号 | `#1, #2, ...`（基于分页计算） |
| 角色图标 | 👤 user (蓝色) / 🤖 assistant (绿色) / 🔧 tool (橙色) / 📄 system (灰色) |
| 数据大小 | `LENGTH(data)` 格式化，带颜色编码 |
| 时间 | 相对时间 |

### 大小颜色编码

| 大小 | 颜色 |
|------|------|
| < 20KB | 灰色 |
| 20KB - 50KB | 红色 |
| > 50KB | 粗体红色 |

### 分页

- 默认 50 条/页
- 上一页/下一页按钮
- 显示当前页/总页数

## 消息详情（右侧，60%宽度）

### 内容渲染

| 角色 | 渲染方式 |
|------|---------|
| user | 蓝色背景，纯文本 |
| assistant | 白色背景，Markdown 渲染（代码块高亮） |
| tool | 检测错误关键词，错误则红色背景 |
| system | 白色背景，Markdown 渲染 |

### Markdown 渲染

使用 `react-markdown` + `remark-gfm` + `rehype-highlight`：
- 支持 GFM 扩展（表格、删除线、任务列表等）
- 代码块语法高亮
- Prose 排版样式

### Part 筛选

顶部筛选按钮组：
- **全部** — 显示所有 Part
- **text** — 仅文本类型
- **tool** — 仅工具调用类型
- **reasoning** — 仅推理类型

显示匹配数量：`(3/5)`

### Part 明细表

| 列 | 说明 |
|----|------|
| 类型 | 带 emoji 的彩色徽章 + 展开/折叠按钮 |
| 大小 | 带颜色编码的大小指示器 |
| 摘要 | 文本预览或工具名 |

### Part 类型配置

| Part 类型 | Emoji | 徽章颜色 | 可展开 |
|-----------|-------|---------|--------|
| `text` | 📝 | 绿色 | 否 |
| `tool` | 🔧 | 蓝色 | 是 |
| `reasoning` | 🧠 | 橙色 | 是 |
| `step-start` | ▶ | 灰色 | 否 |
| `step-finish` | ✅ | 灰色 | 是 |

### Tool Part 展开详情

点击 `🔧 tool` 行展开，显示：
- **工具名称**：`part.toolName`（等宽字体，蓝色）
- **执行状态**：completed 绿色 / 其他红色
- **输入参数**：深色背景代码块，`part.input`
- **输出内容**：深色背景代码块，`part.output`，超过 500 字符可展开/收起

### Token 分解（step-finish）

点击 `✅ step-finish` 行展开，显示：
- 紫色背景卡片
- Token Usage 网格：
  - Input / Output / Reasoning / Cache Read / Cache Write
- 数字带千分位格式化

### 推理过程（reasoning）

点击 `🧠 reasoning` 行展开，显示：
- 橙色背景卡片
- 推理文本内容
- 默认折叠，点击"展开推理过程"显示

## 数据加载

1. 进入页面时加载消息列表（`messages:list`）
2. 点击消息加载详情（`messages:detail`）
3. 详情包含完整 Part 列表，前端做类型筛选
4. 切换页面时重新加载列表

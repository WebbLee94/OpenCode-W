## 创建备份

### 操作

点击"立即备份"按钮，调用 `backup:create` IPC 通道。

### 备份机制

```typescript
// 使用文件复制（非 SQLite backup API）
fs.copyFileSync(dbPath, backupPath)

// 同时复制 WAL 和 SHM 文件（如果存在）
if (fs.existsSync(walPath)) fs.copyFileSync(walPath, backupPath + '-wal')
if (fs.existsSync(shmPath)) fs.copyFileSync(shmPath, backupPath + '-shm')
```

### 命名规则

```
opencode-backup-2026-05-21T14-30-22-123Z.db
```

时间戳使用 ISO 格式，冒号和点替换为连字符以确保文件名合法。

### 备份目录

- 路径：`app.getPath('userData')/backups/`
- 首次备份时自动创建目录
- macOS: `~/Library/Application Support/DBScope-OC/backups/`

### 结果反馈

- 成功：绿色提示条，显示文件名和大小
- 失败：红色提示条，显示错误信息
- 备份中：按钮显示脉冲动画 + "备份中..."

## 备份列表

### 数据加载

调用 `backup:list` 获取所有备份文件信息。

### 列表字段

| 列 | 说明 |
|----|------|
| 文件名 | 带归档图标，截断显示 |
| 大小 | 格式化字节数 |
| 创建时间 | 相对时间 + hover 显示完整时间 |
| 压缩 | 显示 gzip 标签或 "-" |
| 操作 | 恢复 / 删除 按钮 |

### 排序

按创建时间降序排列（最新的在前）。

### 空状态

无备份时显示归档图标 + "暂无备份文件" + "点击上方'立即备份'创建第一个备份"。

## 恢复

### 操作流程

1. 点击备份列表中的"恢复"按钮
2. 弹出恢复对话框，加载备份预览（`backup:preview`）
3. 预览显示备份内容统计：会话数 / 消息数 / Part 数
4. 显示警告："恢复前将自动备份当前数据库，恢复后当前数据库将被替换"
5. 确认恢复


### 恢复机制

```typescript
// 关闭当前数据库连接
dbManager.closeAll()

// 打开备份文件作为新数据库
dbManager.open(backupPath)
```

### 恢复结果

- 成功：显示绿色圆形 ✓ + "恢复成功" + "数据库已从备份恢复"
- 失败：显示红色错误信息

### 备份预览

恢复前通过 `backup:preview` 获取备份文件内容统计：
- 以只读模式临时打开备份文件
- 查询 session/message/part 表的 COUNT
- 查询完成后关闭临时连接

## 删除备份

### 操作流程

1. 点击备份列表中的"删除"按钮
2. 弹出确认对话框
3. 确认删除

### 确认对话框

```
┌──────────────────────────────────────┐
│  🗑️ 确认删除                          │
│  此操作不可撤销                       │
│                                      │
│  确定要删除备份 opencode-backup-...   │
│  文件大小: 812 MB                     │
│                                      │
│  [取消]              [确认删除]       │
└──────────────────────────────────────┘
```

### 安全检查

- 校验文件路径必须在备份目录内（防止路径遍历攻击）
- 同时删除关联的 WAL 和 SHM 文件

## IPC 通道

| 通道 | 说明 |
|------|------|
| `backup:create` | 创建备份，返回 `BackupDTO` |
| `backup:list` | 获取备份列表，返回 `BackupDTO[]` |
| `backup:preview` | 预览备份内容，返回 `BackupPreviewDTO` |
| `backup:restore` | 恢复备份，返回 `{ success, path?, error? }` |
| `backup:delete` | 删除备份，返回 `{ success }` |

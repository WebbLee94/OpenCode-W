## 数据来源

| 指标 | IPC 通道 | SQL / 来源 |
|------|---------|-----------|
| 总大小 | `dashboard:overview` | `fs.statSync(path).size` |
| 会话数 | `dashboard:overview` | `SELECT COUNT(*) FROM session` |
| 项目数 | `dashboard:overview` | `SELECT COUNT(DISTINCT project_id) FROM session WHERE project_id IS NOT NULL` |
| 可回收碎片 | `dashboard:overview` | `PRAGMA freelist_count * PRAGMA page_size` |
| WAL 大小 | `dashboard:overview` | `fs.statSync(path + '-wal').size` |
| Part 行数 | `dashboard:overview` | `SELECT COUNT(*) FROM part` |
| Token 总计 | `dashboard:tokens` | `SELECT SUM(tokens_input), SUM(tokens_output), SUM(tokens_reasoning) FROM session` |
| 估算成本 | `dashboard:tokens` | `SELECT SUM(cost) FROM session` |
| 缓存复用率 | `dashboard:tokens` | `SUM(tokens_cache_read) / SUM(tokens_input + tokens_output + tokens_reasoning + tokens_cache_read) * 100` |
| 健康状态 | `dashboard:overview` / `database:health` | 总页数 (`PRAGMA page_count`)、碎片页数 (`PRAGMA freelist_count`) |
| 工具排行 | `dashboard:toolRanking` | `GROUP BY json_extract(data, '$.tool_name')` WHERE type='tool' |
| Skill 分布 | `dashboard:skillUsage` | `WHERE json_extract(data, '$.tool_name')='skill'` |
| 增长趋势 | `dashboard:sessionTrend` / `dashboard:costTrend` / `dashboard:messageTrend` | 按天 `GROUP BY date()` 返回会话/成本/消息三组独立趋势；支持时间范围过滤 |

## 图表实现

| 图表 | 库 | 类型 | 说明 |
|------|---|------|------|
| Token 分布 | Recharts | PieChart (环形) | 输入/输出/推理三色饼图 + 右侧指标列表；支持日/周/月聚合切换 |
| 增长趋势 | Recharts | LineChart (双线) | 当前时段(实线) vs 上一时段(虚线) 对比；日/周/月粒度切换 |

## 交互

- **一 键 VACUUM**：调用 `database:vacuum`，完成后弹窗显示释放空间
- **WAL Checkpoint**：调用 `database:checkpoint`，将 WAL 日志合并回主数据库
- **刷新**：重新并行加载所有仪表盘数据
- **时间范围切换**：点击 7 天/30 天/90 天/全部按钮，所有图表和统计卡片同步更新
- **时段对比**：增长趋势图默认展示当前时段与上一时段对比（实线 vs 虚线）
- **聚合切换**：Token 分布图支持日/周/月聚合粒度切换
- 未连接数据库时显示引导页面，提供"Connect Database"按钮

## 刷新策略

- 页面加载时并行拉取 fastData + slowData（`Promise.all`），先渲染骨架屏，数据就绪后填充
- 首次加载结果缓存到 `localStorage`（DashboardCache），再次进入时秒开
- 缓存键包含 `timePreset`，切换页面后时间范围保持一致
- 手动刷新按钮覆盖缓存
- 不自动轮询（避免锁定数据库）
- 操作（VACUUM/Checkpoint）完成后自动刷新

## 数据加载流程

```
1. 检查缓存 (localStorage DashboardCache)
2. 若有缓存且 timePreset 匹配 → 秒开骨架 + 异步刷新
3. 若无缓存:
   - 检查数据库连接 (database:health，与数据加载并发)
   - 并行请求 (Promise.all):
     FastData: overview + tokens + toolRanking + skillUsage
     SlowData: trends + projects + health
4. 数据就绪后渲染统计卡片和图表
5. 写入缓存 (含 timePreset)
6. 若任一请求失败，显示错误页面 + 重试按钮
```

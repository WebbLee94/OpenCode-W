# 开发环境搭建

## 一、系统要求

| 要求 | 最低版本 | 推荐 |
|------|---------|------|
| Node.js | 20.11.1 | 20.x LTS |
| npm | 随 Node 安装 | 最新 |
| 操作系统 | macOS 12 / Windows 10 / Linux x64 | macOS |

> 参考 `.nvmrc` 文件确认推荐 Node 版本。

## 二、初始化步骤

```bash
# 1. 克隆仓库
git clone https://github.com/WebbLee94/OpenCode-W.git
cd OpenCode-W

# 2. 切换 Node 版本（如使用 nvm）
nvm use

# 3. 安装依赖
npm install

# 4. 生成测试数据（可选，但推荐首次执行）
npm run generate-fixture

# 5. 启动开发模式
npm run dev
```

启动后 Electron 窗口自动打开，应用自动检测 `~/.local/share/opencode/opencode.db`，未找到则连接 `test-data/test.db`。

## 三、npm 脚本说明

| 命令 | 说明 |
|------|------|
| npm run dev | 启动开发模式（Vite + Electron） |
| npm run build | 构建生产产物 + 打包 |
| npm run lint | ESLint 代码规范检查 |
| npm run preview | 预览构建产物 |
| npm run test | 运行 Vitest 单元测试 |
| npm run generate-fixture | 生成测试数据库 |
| npx tsc --noEmit | TypeScript 类型检查 |

## 四、IDE 配置建议

### 4.1 VS Code
- 安装 ESLint 扩展
- 安装 Prettier 扩展（如使用）
- 配置 `editor.formatOnSave: true`

### 4.2 WebStorm
- 启用 ESLint
- 配置 TypeScript 严格模式

## 五、项目结构概览

（参考 [02-架构设计/01-整体架构.md](../02-架构设计/01-整体架构.md)「目录结构」段）

关键目录：

- `src/` — 渲染进程（React 18）
- `shared/` — 共享类型与 IPC 常量
- `docs/` — 文档（8 维度分类）

## 六、调试技巧

### 6.1 主进程调试
- DevTools → Main Process（需启用）
- 或在代码中 `console.log`，输出在终端

### 6.2 渲染进程调试
- DevTools（Renderer）→ Console / Sources
- React DevTools 扩展

### 6.3 数据库调试
- 用 DB Browser for SQLite 直接打开 `test-data/test.db`
- 或运行 `npm run inspect-db`（如有）

## 七、常见问题

### Q: 启动报 "Cannot find module 'node:sqlite'"?
A: 确认 Node ≥ 22.5，Electron 42 内嵌 Node 24.15 默认可用。

### Q: better-sqlite3 相关报错?
A: v1.2.0 已移除 better-sqlite3，确保 package.json 无残留依赖。

# 产品需求文档（PRD）

> 版本：v1.2.0  | 更新日期：2026-07-07

## 一、产品定位

OpenCode-W 是 AI 编程工程工坊，将每次 OpenCode 对话沉淀为可分析的数据资产——Token 消耗、工具偏好、模型 ROI、成本趋势——用数据驱动编程工程化。

W = Workshop（工坊）+ 作者 Webb 印记。

## 二、目标用户

**核心用户**：每周用 OpenCode 产生数十上百次 AI 对话、想看清花费和效率、希望从「凭感觉写」进阶到「凭数据工程」的开发者。

**用户画像**：
- 痛点：不知道 AI 编程花了多少钱、找不到历史对话、旧数据堆积不敢删
- 期望：一眼看清全貌、安全清理、可追溯的历史

## 三、核心用户故事

| ID | 作为 | 我想要 | 以便 |
|----|------|--------|------|
| US-01 | 开发者 | 看清 Token 消耗与成本趋势 | 优化 AI 编程 ROI |
| US-02 | 开发者 | 按项目/时间浏览所有历史会话 | 找回关键对话 |
| US-03 | 开发者 | 原生渲染 AI 对话流（含 12 种 Part） | 复盘编程过程 |
| US-04 | 开发者 | 安全清理旧数据（预览+确认） | 释放磁盘空间 |
| US-05 | 开发者 | 备份与恢复数据库 | 防止数据丢失 |
| US-06 | 开发者 | 批量迁移会话到指定项目 | 按项目集中管理 |
| US-07 | 开发者 | 全文搜索消息内容 | 定位关键方案 |

## 五、非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | Dashboard 3 秒内加载完成 |
| 安全 | contextIsolation + 破坏性操作预览+确认 |
| 兼容 | macOS 12+ / Windows 10+ / Linux x64 |
| 数据 | 支持 OpenCode v1.x（parent_id 列） |
| 启动 | 自动检测 opencode.db，零配置 |

## 六、明确不做

- 通用 SQL 执行（聚焦 OpenCode 数据）
- 通用数据库支持（仅 SQLite）
- 文件导出（v1.2 移除）
- 分享管理独立页（v1.1 移除）
- 自动备份调度（v1.1 移除）

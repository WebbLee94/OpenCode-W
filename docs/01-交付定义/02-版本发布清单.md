## 二、Definition of Done（DoD）

一个版本可发布当且仅当：

- [ ] 所有 P0 功能通过手动测试
- [ ] `npx tsc --noEmit` 无错误
- [ ] `npm run lint` 无错误
- [ ] CI 4 平台构建通过（macOS arm64/x64、Windows x64/arm64、Linux x64）
- [ ] CHANGELOG.md 已更新
- [ ] package.json 版本号已更新
- [ ] git tag 已打
- [ ] GitHub Release 已发布

## 三、发布流程

1. **版本准备**
   - 更新 CHANGELOG.md（按 Keep a Changelog 格式）
   - 更新 package.json version
   - 提交：`chore: 发布 vX.Y.Z 版本，包含...`

2. **CI 验证**
   - 推送到 release 分支
   - 等待 CI 4 平台构建通过
   - 检查产物大小与签名

3. **打 tag**
   - `git tag vX.Y.Z`
   - `git push origin vX.Y.Z`（需用户明确授权）

4. **GitHub Release**
   - 基于 tag 创建 Release
   - 粘贴 CHANGELOG 段落
   - 上传构建产物（.dmg / .exe / .AppImage）

5. **合并到 master**
   - PR: release → master
   - 至少 1 名维护者 Review

## 四、CI 平台矩阵

| 平台 | 架构 | 构建工具 | 产物 |
|------|------|---------|------|
| macOS | arm64 + x64 | electron-builder | .dmg (Universal) |
| Windows | x64 + arm64 | electron-builder | .exe (NSIS) |
| Linux | x64 | electron-builder | .AppImage + .deb |

## 五、回滚策略

- 版本发布后发现严重 Bug：发布 patch 版本修复
- 不删除已发布版本（保留历史）
- GitHub Release 可标记为 "pre-release" 降级

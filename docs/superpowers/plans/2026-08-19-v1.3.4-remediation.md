# v1.3.4 Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix directory reveal and backup timestamp regressions, remove large-database hot-path bottlenecks without changing OpenCode tables, and safely add the updater fix to v1.3.4.

**Architecture:** Keep OpenCode's SQLite schema untouched. Use a server-validated database-path snapshot for shell reveal, explicit UTC timestamps at the IPC boundary, a lightweight health command for UI hot paths, and a bounded five-second in-process fork-attribution cache with explicit invalidation. Consolidate repeated analytics work only after preserving existing DTO and logical-dedup semantics. Keep optional indexes in a separate manual-evaluation document and never execute them from the app.

**Tech Stack:** React 18, TypeScript, Vitest, Tauri v2, Rust 2021, rusqlite/r2d2, SQLite, GitHub Actions updater artifacts.
